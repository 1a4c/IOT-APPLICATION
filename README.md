新增功能與產品類別結構說明：
左上角「3C 產品選擇矩陣」：

Smart Phone（智慧型手機）：綜合運用多鏡頭對焦（3D 全息）、抗干擾（白雜訊濾波）與高溫散熱壓制（熱氣球閥）。

Spatial VR/AR（空間運算頭顯）：主打 3D 歐幾里得全息渲染與視覺濾波。

Smart Watch（穿戴裝置）：側重生醫 TAP 雜訊濾波與 U 型帶寬省電結構。

Automotive 3C（車載電子）：強化高溫防護（heat balloon）與機械打擊/震動抑制（strike suppressed）。

動態 DSL 代碼切換：切換不同產品類別時，左下方的 DSL 定義碼會即時變化，動態展示對應的 active_layers 配置。

單晶片面積與光罩數量試算：點擊右側的「編譯該 3C 產品光罩」按鈕後，晶片視口只會點亮該 3C 產品所需的光罩模組，並重新計算其晶片面積與 GDSII 多邊形數量。
